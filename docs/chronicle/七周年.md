# 七周年庆
OurWord Community 七周年庆 将于 `2025.7.1`开启！

### BOSS战
七月到八月间，击败末地世界的末影龙将开启周年BOSS战  
* 每一阶段的BOSS都会掉落特殊战利品
* 所有活动敌对目标的战利品都会直接发放给死亡时所有处于参战状态的玩家(注意留出背包空位)
* 末影龙可以照常复活！

### 空间棱镜上线
现在所有的资源世界可以使用道具`星屑收纳棱镜`将任意结构保存，以便在资源世界刷新时保留结构。  
保存的结构也可以在线预览或导出为结构投影文件  
[例子](https://ocess.smyhw.online/fe/viewer/?id=mtwMFsrskWwSLGrY)  
也提供了一个[校验页面](https://ocess.smyhw.online/fe/verifier/)，该页面可以上传并校验文件是否由本服务器导出  
具体方式请参照[结构系统]()页面
