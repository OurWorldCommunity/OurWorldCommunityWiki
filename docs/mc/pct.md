# 库存系统

> 也是咱的原创插件啦...  

这是一个便携式背包系统

当玩家拥有*背包时限*时可用，使用`/pct`打开个人背包

## 空间大小
初始情况下，玩家的便携背包只有一行(9格)  
在不考虑特殊活动的情况下，玩家可以对背包进行一次升级，额外扩充一行
> 升级方法？保密！自己找找咯awa  

空间大小不会影响获取*背包时限*的时长！

## *背包时限*获取方式
* 在主城的某处可以换取道具*反影轮回*，使用可获取一定*背包时限*
* 部分任务可以获取*反影轮回PLUS*，使用可以获取更长时间的*背包时限*
* 部分活动也会奖励或发放*背包时限*


## FAQ
**如果*背包时限*过期，背包里的物品咋办？**  
*仍保留在背包中，当下次拥有背包时限时可取出*

**咱如何查看拥有多少*背包时限*？**  
*唔，暂时不能查看*

**多次使用道具，时间会叠加嘛？**  
*不会！*
